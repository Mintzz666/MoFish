## 2026-10-20：新增造景的编辑对象不清楚

用户反馈添加造景时难以辨认当前操作的是哪一件。原有浅色脚下细圈接近沙面颜色，且可能被沙面遮挡。
改为当前物件本身暖金色高亮，加上有深色边缘的金色定位圈；定位圈按实际几何和缩放适配，
移动、旋转、缩放、换造型后持续跟随。取消或完成布景时恢复原材质，效果不写入个人外观或云端存档。
减少动态效果的设备使用静态定位圈。2D原有禁止编辑行为保留。

实际截图检查还发现部分小石头几何低于沙面而不可见：在一个固定沙面位置/0.85缩放下，
64个溪卵石seed中15个的整个几何顶面低于沙面。修正为几何底部贴合当地沙面，保持x/z/seed/scale等存档字段不变。

窄屏实际截图发现旧浮动条会遮住矮造景，故将编辑工具放到画面下方（仍在鱼缸区内），保留44px触控按钮。

## 2026-10-20：选中造景后缺少确认退出

用户在桌面 Safari 的 C 测试入口选中已有沉木，反馈工具条应有确认退出按钮。
原实现只有新物件待放置时显示「放在这里」，已有物件选中后缺少就地退出入口。

修复：选中已有造景时，鱼缸内工具条显示绿色「完成布景」。点击保留当前调整，取消选中、收起工具条并回到观赏模式。
新增物件继续显示「放在这里」和「取消」，放好后可继续调整，再点「完成布景」退出。
只更新独立 C Worker，不改 A/B Worker、数据库权限、账号、用户存档，不触发正式发布。
