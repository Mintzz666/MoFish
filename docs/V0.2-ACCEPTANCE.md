# MoFish V0.2：体验与资源优化

目标版本 `0.2.0`，界面显示「V0.2 测试版」。这是独立 C 测试入口的升级，不代表用户接受、main 合并、Git 标签或正式 release。
基线为 `9796313204aa4afe2b2042a2e3d338bb83bc6235`，使用同一独立工作树和分支 `codex/v0.2-ux-performance`。

## 体验变化

- 鱼缸与对象详情组成工作区：桌面侧栏、窄屏可展开面板；账号、当前鱼缸和同步状态集中在顶部，画质/声音/存档等次要设置收进「更多」。
- 观赏、逗鱼、布景有独立状态；轻触水面只产生涟漪与回应，喂食使用「喂一点」按钮或空格。拖动、多指和取消手势不触发点击。
- 造景有高亮、定位圈、确认/取消/完成布景；增加造景选择列表，遮挡或小物件也能明确选中。选鱼切换到成长详情，保留键盘焦点和最少44px的常用触控区域。
- 账号界面说明测试账号与 A 环境独立；恢复邮件提示说明请求已提交，不保证实际邮件送达。
- 2D保留正立的插画鱼和已有造景外观；帧率/分辨率策略同样适用于2D。不支持的布景和逗鱼功能仍引导到3D。

## 资源与升级机制

默认自动省电：闲置目标30帧，操作期间最多60帧，结束3秒回落。低于目标能力时按工作量和呈现延迟留出闲置预算；不把短暂的JavaScript提交时间误当成GPU已完成。
运行策略使用3秒采样窗、升降档滞回和10秒冷却，调整分辨率、阴影与粒子，不反复销毁场景。后台和鱼缸离屏暂停绘制；存档与必要权限检查继续运行。

2D复用排序缓冲和有界石木绘制缓存；鱼卡片按对象更新，避免反复整体重建。低档体素保留同一细网格采样规则，直接汇总到最终占用格，省去高分辨率体素数组和额外下采样遍历；没有声称细格采样循环完全消失。
直接更改采样网格的首次尝试因轮廓尺寸偏移被撤回，最终路径保留尺寸和种子确定性，并通过原几何检查。

3D及Three.js按需加载，2D不预取3D包。静态资源用内容寻址文件名，构建清单带版本、源码SHA和资源SHA256。
Service Worker先完整下载并验证对应构建的shell，失败不接管；有更新时提示，未保存/未同步或冲突未处理时不重载。
旧页面报告所用入口，仍有页面使用或尚未确认用途的旧缓存保留。新会话基础离线保证2D，用过并缓存完成的3D可离线恢复；从未下载的3D不作离线保证。
音频节点复用、开关偏好只存本机；返回前台、聚焦和联网恢复的同步请求合并，不延长原成员权限核验间隔。

## 检测方法与边界

性能基线和候选都固定种子、日期、1440×900视口和独立Chromium配置；默认鱼缸与合法满配分别预热10秒，再采样60秒、重复3次。
满配为12鱼、14草+6石+4木，共24件造景；各分类上限不能相加绕过全局24件限制。
CPU工作量使用CDP TaskDuration增量除以墙钟时间；同时记录RAF间隔、JS堆、Three绘制/几何/纹理、请求和包体。帧目标不等于实际达到帧数。
实际GL为SwiftShader软件渲染；结果只支持同环境前后对照，不等于物理GPU、真实手机功耗或温度。
短时启动探测和暴露异步渲染瓶颈的首轮候选保留，但不混入最终三轮统计。

严格测试包含真实本机PostgreSQL；完整页面回归使用假后端，真实QA HTTP和双账号页面另行记录，互不替代。
15分钟稳定性验证包含20轮渲染/画质切换、50次换型并撤销，回到相同状态后比较资源和回收后的堆；先预热首次使用的选中环和着色器资源。

## 数据与发布边界

继续使用存档v2和现有4份数据库迁移，没有新增后端接口或数据库结构。
仅部署独立 `mofish-phase-c`，保留 A、B、Tibo、Sites、令牌和用户存档，不新增收费资源。
真实云检查只使用随机登记的临时身份，并核对归属后清理；浏览器、预览与临时profile只处理本任务创建的实例。
源码审阅与截图复核额外发现并修复：未问候2D鱼的无穷时间导致Canvas非有限变换；样式括号缺失使后续适配规则失效；更新保存期间可新增待确认物件的竞态；低档新建造景临时分配阴影平面造成资源计数差异。分别补绘制参数、实际双栏几何/触控尺寸、更新保护和稳定性检查。
低档造景统一使用沙面环境明暗，不再按创建时机分配独立接触阴影；慢帧内按不超过50ms子步推进游动，避免仅因降低绘制频率减慢转向。

完整日志和截图在Git忽略的 `.local/v02-20261023/`，不提交凭据、用户存档或账号登记。

真实手机触控/温度/电量、实际听感、邮箱送达和用户最终审美接受继续标为待确认。本轮不要求用户参与，也不由自动化代签接受。

## 性能与稳定性

最终对照见公开 [机器可读概要](evidence/v02-20261023.json)。最终基线和候选均使用 Chrome 155.0.8059.86、同一SwiftShader、固定种子与1440×900视口；
旧部署 `2282ce2` 与指定基线 `9796313` 的差异仅为文档，应用代码一致。
原先浏览器自动升级前的数据及中途发现问题后主动停止的采样保留，未计入最终对照。

CPU工作量比较旧默认高画质与新默认自动策略，包含画质、分辨率、绘制次数和布局的共同变化。
这是默认体验的整体对照，不是相同画质/帧率下的算法提速。实际绘制频率另列，RAF回调间隔不能当鱼缸FPS。
此软件渲染环境未达到目标30帧，不能据此声称真实GPU或手机达到30/60帧，也不能换算整机电量或温度。
运动按时间与小子步推进；超过250ms的单次严重停顿仍有追赶上限，前后台恢复会重置时钟，成长由服务端时间核算。
