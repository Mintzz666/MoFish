## 实现与保护

主人、可编辑、仅观看三种权限；主人创建指定已验证邮箱可用的一次性代码，有效 1 小时至 7 天，
支持撤销、调整角色和移除成员。代码只显示一次，可复制，应用不发送邀请邮件。
每人保留个人缸，可进入已加入缸；成员关系和当前身份由数据库检查，不接受客户端自报角色。

C 使用语义操作及 UUID 队列，事务内对鱼缸加锁并去重；不同物件合并，同一物件基线冲突保留本机副本。
选择保留本机仅重新应用目标物件操作，保留伙伴其他新增内容；冲突两种选择均留备份。
成长与进食仍服务端权威，viewer不能写/喂食/结算。共享缸拒绝旧 B 整缸 `save_aquarium` 覆盖，
因此已开始共享的账号应在 C 编辑；未共享个人缸继续兼容原 B 路径，真实 B 回归另行验证。

Realtime 只发送 `mofish_room_revisions` 的小型版本提示，随后重新授权取回快照；不广播邮箱/存档/逐帧鱼位姿。
连接成功与数据库复制就绪分开处理，后端 READY 时补取状态；断线恢复/前台约15秒轻量权限检查兜底。
撤销后拒绝新读写及通知；离线缓存、截图或先前导出不可能远程抹除，后台暂停期间也不承诺即时清屏。

本机队列按账号和鱼缸隔离，响应代次和旧频道清理防止换号串档。个人缸可在已有缓存和会话时离线重开。
重新启动默认回个人缸；其他共享缸队列仍保留，联网后可从列表重进。已被伙伴移走的鱼不会卡死进食队列。
旧 B 未上传整缸副本先归档到账号备份，不静默转成协作覆盖；旧进食队列保留 operation_id。

视觉/交互整体打磨：保留奶油白/青绿、实体玻璃和体素鱼，统一卡片层次、焦点和禁用反馈；手机常用控件
至少44px高，窄屏顶栏/造景工具条换行，共享弹窗内部滚动和安全区；减少动态效果偏好继续有效。
主人个人缸不显示无意义的“返回个人”横幅，受邀角色明确显示，具体失败原因可见，输入不被同步刷新擦除，面板提供邀请/接受/切换快捷导航。云端协作模式禁止整缸导入并说明游客导入路径；伙伴更新取消未确认造景时明确提示。
